# 🚀 Rural Micro-Business Failure Prediction System

AI-powered system to predict failure risk of rural micro-businesses using machine learning.

## 🌐 Live Demo
👉 https://rural-business-risk-app.streamlit.app/

## 🧠 Features
- Hybrid Dataset (Kaggle + Synthetic)
- ML Models: Random Forest & XGBoost
- Risk Prediction Dashboard
- Cash Flow Analysis

## 🛠 Tech Stack
- Python
- Streamlit
- Scikit-learn
- XGBoost
